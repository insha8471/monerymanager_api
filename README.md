# 💰 Money Manager API

A **Spring Boot–based RESTful backend** for managing personal finances — track income, expenses, and spending categories securely.

---

## 🚀 Tech Stack
- **Spring Boot**
- **Spring Security**
- **JPA (Hibernate)**
- **PostgreSQL**
- **DBeaver** – for database design & relations
- **Docker** – containerization
- **Render** – cloud deployment

---

## 🔐 Features
- Secure **user authentication & authorization** using Spring Security  
- **CRUD** operations for income, expenses, and categories  
- **ORM** integration using JPA & Hibernate  
- Well-structured **PostgreSQL** database designed with DBeaver  
- **CORS configuration** for React or other frontends  
- Deployed on **Render** for public access
